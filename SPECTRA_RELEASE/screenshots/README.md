# Final Screenshot Checklist

Place final, presentation-resolution screenshots in this folder using these
exact filenames:

| Filename | Required content |
|---|---|
| `01_main_interface.png` | Full SPECTRA interface with receiver connected |
| `02_live_fft_waterfall.png` | Clear live FFT peaks and waterfall history |
| `03_survey_progress.png` | Survey visibly in progress |
| `04_survey_complete.png` | Completed survey and recommendation state |
| `05_SMART_report.png` | Detailed recommendation, comparison, score, and diagnostics |
| `06_auto_tune_result.png` | Receiver on the recommended channel |

Before capture:

- use the final release revision;
- close unrelated applications and notifications;
- avoid clipping, cursor obstruction, or private information;
- use consistent window dimensions; and
- verify every displayed value is technically defensible.

No placeholder image files are included because empty PNGs could be mistaken
for completed evidence.
