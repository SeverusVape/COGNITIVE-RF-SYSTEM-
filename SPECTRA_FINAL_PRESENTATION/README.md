## Presentation Boundaries

- SPECTRA is receive only.
- SMART is deterministic heuristic scoring, not AI or machine learning.
- Power values are relative and are not calibrated dBm.
- Context descriptors are not modulation, service, or transmitter
  identification.
- REAL-RF replay demonstrates repeatability, agreement, and runtime behavior,
  not absolute detector accuracy without ground truth.

No PPTX file is included at this stage.
