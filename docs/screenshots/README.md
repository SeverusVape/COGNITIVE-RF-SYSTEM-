# SPECTRA Release Screenshots

This folder contains the final demonstration screenshots selected for the
public SPECTRA engineering documentation.

See `SCREENSHOT_INDEX.md` for the purpose, demonstration stage, and visible
engineering evidence associated with each image.

## Included Assets

| Filename | Presentation purpose |
|---|---|
| `start.png` | Introduce the complete live application and connected receiver |
| `fft_and_waterfall.png` | Explain FFT peak candidates and temporal waterfall activity |
| `survey_running.png` | Demonstrate event-driven automated survey progress |
| `survey_complete.png` | Show the completed survey, recommendation, and recommended-channel state |
| `smart_report_top.png` | Explain the SMART winner, runner-up, separation, and score components |
| `smart_report_diagnostics.png` | Show lower report diagnostics and frequency-coverage evidence |

## Capture Requirements

Final screenshots should:

- come from the approved release revision;
- use presentation-readable resolution and scaling;
- show technically consistent frequency, score, and status values;
- avoid tuning transients, errors, and contradictory states;
- preserve relative-power and spectral-bin-occupancy terminology;
- avoid cursor obstruction; and
- remain unedited except for non-misleading cropping or resizing.

## Privacy and Publication Notes

The supplied images do not expose repository paths, terminal commands,
personal filenames, or validation dataset contents.

Some full-window captures include macOS interface chrome, date/time, weather,
battery state, and application icons. Review those elements against the
institution's publication policy before placing the images in a public paper
or website. If required, recapture with the menu bar and Dock hidden rather
than altering engineering content.

Do not include:

- notifications;
- account names or personal messages;
- unrelated open documents;
- precise private location information; or
- hardware serial numbers.

## Presentation Usage

Recommended order:

1. `start.png`
2. `fft_and_waterfall.png`
3. `survey_running.png`
4. `survey_complete.png`
5. `smart_report_top.png`
6. `smart_report_diagnostics.png`

Use the full-interface images to explain workflow and the cropped images to
explain detailed DSP or report evidence. Do not interpret any screenshot as
calibrated RF measurement, ground-truth signal identification, or
statistically validated detector accuracy.
